How it works

Press. Check. Paste.

Press the hotkey

⊞ + Shift + Q on Windows. ⌘ Cmd + Shift + 8 on a Mac. Ctrl + Alt + Q on Linux. Or set your own.

Read the card

The code is copied. A card shows where the link really goes, with any warning in amber.

Open it, or paste it

Web links get an Open button, and a link without https:// opens with https. Wi-Fi, contacts and app links are copy only.

Try the card

Built in

Small app. Lots of thought.

Scam checks

Every link is checked on your computer for short links that hide the real site, borrowed brand names, and endings like .zip. A link with a warning shows its card before anything opens.

Every screen at once

A scan covers your whole desktop, every monitor. Each card appears on the screen its code is on.

Styled codes

Dots, rounded blocks, a logo in the middle, colors, dark mode, codes at an angle, and codes down to about 45 pixels.

Start at login

It asks once, on first run, and never turns anything on unless you say yes. Change it any time from the tray.

Your hotkey

Set your own with one option. On Windows, a taken key falls back to the next free one, and the startup card says which.

Works with Do Not Disturb

The card is UniQR's own window, not a notification, so focus modes can't hide it.

Scan an image file

uniqr-scan photo.png reads codes from a picture, no screen needed.

Help from the tray

Report a problem opens a pre-filled GitHub issue. Send feedback opens the discussions. Uninstall UniQR removes it. UniQR sends nothing itself.

Measured, not claimed

A wrong link is worse than no link.

So the benchmark counts wrong answers on their own. Codes are generated in 19 styles and code types, then damaged: rotated, blurred, tilted, compressed, in glare, or dropped onto a busy 1080p page.

Sources: benchmarks/RESULTS.md (seed 7) and cpp/README.md (seed 11). Two separate runs. Backed by 500+ Python tests and 60+ C++ tests, across 19 releases.

Private by design

It only looks when you ask.

  • Nothing is captured until you press the key.
  • No background scanning and no scan history.
  • Your scans never leave your machine.
Get UniQR

Try it out.

Free and open source, MIT licensed. Every release is at github.com/pat-selby/uniqr/releases/latest.

Windows

Download UniQR.exe and double-click it. No Python needed. Windows may warn the first time, since it isn't code-signed yet.

Download for Windows

Mac

Download the .dmg and drag UniQR to Applications. Open it, then click Open Anyway in System Settings > Privacy & Security. Switch UniQR on under Screen Recording and Accessibility. Needs macOS 14 or newer.

Apple SiliconIntel

Linux

Download UniQR-linux-x86_64. It needs an X11 session, since Wayland blocks screen capture.

Download for Linux

Why does Windows warn? It isn't code-signed yet. Read the Code signing policy. Questions or ideas? Ask in Discussions.
