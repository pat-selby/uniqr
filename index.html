How it works

Press. Check. Paste.

Press the hotkey

Windows logo key + Shift + Q on Windows. Command + Shift + 8 on a Mac. Ctrl + Alt + Q on Linux.

Read the card

One code is copied right away. A card under it shows the real host in bold, the rest of the address dimmed, and any warning in amber.

Open it, or paste it

Only plain web links get an Open button. Wi-Fi codes, contacts and app links are copy only.

Styled codes

Dots, rounded blocks, a logo in the middle, colors, dark mode, codes at an angle, and codes down to about 45 pixels.

Start at login

It asks once, on first run, and never turns anything on unless you say yes. Change it any time from the tray.

Your hotkey

Set your own with one option. On Windows, a taken key falls back to the next free one, and the startup card says which.

Works with Do Not Disturb

The card is UniQR's own window, not a notification, so focus modes can't hide it.

Scan an image file

uniqr-scan photo.png reads codes from a picture, no screen needed.

Report a problem

One click in the tray opens a pre-filled GitHub issue. UniQR sends nothing itself.

Measured, not claimed

A wrong link is worse than no link.

So the benchmark counts wrong answers on their own. Codes are generated in 19 styles and code types, then damaged: rotated, blurred, tilted, compressed, in glare, or dropped onto a busy 1080p page.

96.8%decoded, of 1,064 generated test codes in 7 formats

0false alarms, on 48 images with no code

Then it was rebuilt in C++

Median scan time on the same 1,064 codes. Python read 1,027 and C++ read 1,026, both with 0 wrong. The C++ app is one 1.9 MB exe.

Sources: benchmarks/RESULTS.md (seed 7) and cpp/README.md (seed 11). Two separate runs. Backed by 481 Python tests and 63 C++ tests, across 13 releases.

Private by design

It only looks when you ask.

  • Nothing is captured until you press the key.
  • No background scanning and no scan history.
  • Your scans never leave your machine.
